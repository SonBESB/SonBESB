# data/raw

Contains the original source workbook, unmodified:

- `Codos_HDPE_Parametricos_DIN16963.xlsx`

Do not edit this file. To update or extend the catalog, replace it with a
new workbook that keeps the same sheet names and column headers expected by
`data/loader.py` (`BD_Codos`, `BD_PN`, and one `Codo <angle>` sheet per
angle), or update `data/loader.py` if the layout changes.
